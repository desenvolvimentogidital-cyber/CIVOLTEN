# Site institucional CIVOLTEN

Esta pasta reúne CSS, JavaScript e imagens da página pública `empresa.html`, exibida no domínio principal por redirecionamento de `/` para `/empresa`.

A aplicação original em `index.html` não foi alterada e uma cópia de entrada está em `painel.html`, acessível por `/painel`. As APIs, o Supabase, os cálculos e a geração de PDFs permanecem iguais.

As imagens da área de referências são ilustrativas, não representam obras comprovadamente executadas. Contato comercial pode ser adicionado quando houver canais oficiais.

A marca é carregada dos dois arquivos PNG originais já existentes em `/assets/`.
